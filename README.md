# ChaosKit Minimized

Refer to <https://github.com/gremlin/chaoskit> for repo info.

## About this branch

It's a long-running, specialized branch intended for use in internal applications.

It contains certain `src` files and the published assets from v4.7.0. Only a few needed `dependencies` are specified - the rest have been moved to `peerDependencies`.

**It's not intended to be merged back to `master`.**

Pull requests can be made against it, but **it must not be deleted while in use.**
